# PRD (제품 요구사항) — AI 옷장

작성 기준: 2026-10-20, `main` 커밋 `1b1c6f1`. 범위는 `docs/mvp.md`, 구현 구조는 `docs/tech-spec.md`.

## 1. 화면 구성

| 화면 | 들어가는 조건 | 주요 동작 |
|---|---|---|
| 로그인 / 회원가입 | 공개 배포 모드에서 로그인 전 | 이메일·비밀번호로 가입 또는 로그인 |
| 홈 | 로그인 후 | 서비스 소개, 무료 서비스 안내 |

로컬 모드(설정 없음)에서는 로그인 화면 없이 사이드바에서 사용자를 고른다.

## 2. 기능 요구사항

### F-01 가입·로그인 (M-1)
- 회원가입: 이메일, 비밀번호(6자 이상), 비밀번호 확인. 이메일 인증을 끈 설정이면 가입 즉시 로그인된다.
- 로그인 상태는 브라우저 세션마다 따로 유지된다. 로그아웃하면 로그인 화면으로 돌아간다.
- **수용 기준**: 가입 → 메뉴가 보임 / 틀린 비밀번호는 거부 / 로그아웃 후 다시 로그인하면 내 데이터가 그대로 있음.

### F-02 프로필 (M-2)
- 이름, 성별(남성/여성), 체감 성향 5단계(추위를 잘 탐 ~ 더위를 잘 탐).
- 체감 성향은 추천의 기온 보정(최대 ±3℃)에 쓰인다. 성별은 스타터 옷장 구성에 쓰인다.
- 공개 배포 모드에서는 계정당 프로필 1개. 프로필이 없으면 다른 화면에서 "프로필을 생성하세요"를 안내한다.

### F-03 옷장 관리 (M-4, S-2)
- 목록: 사진, 이름, 대분류/세부분류, 두께(1~5), 입는 계절, 색상, 비 적합 여부, 소재별 세탁 안내.
- 필터: 카테고리, 계절, 이름·세부분류 검색.
- 비활성화(넣어 두기): 목록과 추천에서 빠지고 '넣어 둔 옷'에서 다시 꺼낼 수 있다.
- 삭제: 목록에서 숨긴다(소프트 삭제). 과거 추천 기록은 유지된다.
- 계절 정리: 지금 계절에 안 입는 옷을 한 번에 넣어 두고, 넣어 둔 옷 중 지금 계절 옷을 한 번에 꺼낸다. 옷마다 입는 계절을 직접 고칠 수 있다.

### F-04 스타터 옷장 (M-3)
- 프로필 성별 기준 캐주얼 옷 30벌을 한 번에 추가한다. 같은 이름이 이미 있으면 다시 넣지 않는다.

### F-05 사진으로 옷 등록 + AI 분류 (M-3)
- JPG/PNG 업로드(최대 20MB) → 대표색 추정 → [AI 분류 시도] → 42종 중 가장 확률 높은 세부분류와 확신도(%) 표시.
- 세부분류를 고르면 대분류·두께·비 적합 기본값이 규칙표에서 채워진다. 사용자가 모두 고칠 수 있다.
- 저장 시 의류명과 사진은 필수. 사진은 긴 변 1280px JPEG로 줄여 내 계정 폴더에만 저장한다.

### F-06 날씨 (M-5, S-1)
- 자동 조회: 도시 8곳(인천·안양·서울·수원·대전·대구·광주·부산) 중 선택, 귀가 예정 시각(18/20/22/24시) 선택 → [현재 날씨 불러오기].
- 수동 입력: 기온, 체감온도, 습도, 강수량, 풍속, 비가 옴, 저녁 늦게까지 밖에 있어요 + 저녁 체감온도.

### F-07 코디 추천 (M-6)
- 외출 목적 4가지: 등교 / 데이트 / 운동 / 격식.
- [TOP 3 추천 생성] → 순위, 점수, 코디 구성, 추천 이유, 점수 근거.
- 비즈니스 규칙은 3절.

### F-08 저장·피드백 (M-7)
- [이 코디 저장]: 같은 추천을 두 번 저장해도 1번만 저장된다. 저장하면 그 추천 세션이 '완료'로 기록된다.
- [👍 좋아요] / [👎 별로]: '별로'를 누른 조합은 다음 추천에서 빠진다.
- 착용 후 피드백: 체감(매우 추움 ~ 매우 더움), 코디 만족도(1~5), 실제로 착용함.

### F-09 사기 전에 맞춰보기 (S-3)
- 상품 사진(또는 캡처), 종류, 색, 두께/보온, 비 오는 날 부담 여부, 이름, 상품 링크(선택, 메모용)를 넣고 [구매 후보로 저장].
- 판정은 3절 규칙. 계절(여름/봄·가을/겨울) × 목적 4가지 상황별 코디 예시를 보여 준다.

### F-10 저장 코디 / F-11 KPI·데이터 (M-8)
- 저장 코디: 저장한 추천을 다시 보여 준다.
- KPI: 추천 세션 수, Top 3 수용률 = 코디를 1개 이상 저장한 세션 ÷ 전체 추천 세션.
- 추천 로그 CSV 내려받기 (내 기록만).

### F-12 가상 착용(예시) (S-5)
- 버튼 표시 조건: 설정에 Space 주소가 있고, 옷이 상의·하의·원피스·아우터일 때 (신발 제외).
- 위치: 옷장 카드, 추천 결과, 구매 후보.
- 여러 벌이면 최대 2벌 선택. 기본은 상의(또는 원피스) + 하의. 입히는 순서는 하의가 마지막.
- [새 창(Hugging Face)에서 열기 · 권장]과 앱 안 창 두 가지. 옷 사진 주소는 10분짜리 서명 주소로 넘긴다.
- 사람 사진은 AI 옷장에 저장하지 않는다. 결과는 'AI가 그린 예시'이며 사이즈·핏 미반영이라고 표시한다.

### F-13 웹 체험판 (S-6)
- 설치·로그인 없이 브라우저에서 추천과 사진 분류. 날씨는 직접 입력, 옷장은 브라우저에 저장.
- 추천·분류·계절·구매 판정 결과가 앱(Python)과 같아야 한다.

## 3. 비즈니스 규칙

### 추천 (`core/recommender.py`, 규칙표 `data/clothing_taxonomy.csv`)
1. **유효 기온** = 체감온도(없으면 기온) + 체질 보정(최대 ±3℃) + 운동이면 +5℃ + 20℃ 미만에서 비 오면 −1℃.
2. 규칙표의 42종마다 대분류, 기본 보온값(1~5), 방수 여부, 착용 가능 기온 범위, 금지 목적이 있다. 범위 밖이거나 금지 목적인 옷은 후보에서 뺀다.
3. 조합: 상의+하의(또는 원피스)+신발, 필요하면 겉옷. 유효 기온 **12℃ 이하면 겉옷 필수**, **24℃ 이상이면 상의 겹쳐 입기 안 함**. 어울리지 않는 쌍(예: 구두+조거팬츠)은 뺀다.
4. **점수 = 0.60 × 날씨 + 0.25 × 비 + 0.15 × 색 조합**. 외출 목적은 점수가 아니라 2·3번 거르기로 반영한다. 습도·풍속은 점수에 넣지 않는다.
5. 비슷한 코디를 걸러 상위 3개. '별로' 조합 제외.
6. 일교차: 귀가 전 가장 추울 때의 유효 기온이 지금보다 3℃ 이상 낮고 보온이 0.35 넘게 모자라면 겉옷 챙기기를 안내한다. 자동 조회는 시간별 예보에서 찾고, 수동 입력과 웹 체험판은 직접 넣은 저녁 기온을 쓴다.

### 계절
- 옷 종류의 착용 가능 기온 범위가 여름 28℃ / 봄·가을 11·16℃ / 겨울 0℃를 포함하면 그 계절. 사용자가 고친 값이 우선한다.

### 구매 판정 (`core/shopping.py`)
- 판정 순서: **중복**(같은 종류·같은 색 옷이 이미 있음) → **코디 없음** → **빈 곳 채움**(어떤 상황에서 최고 점수가 0.05 이상 오르거나, 원래 없던 코디가 생김) → **잘 어울림**.

### 데이터 소유와 권한
- 모든 데이터는 계정 소유. 사용자는 자기 행·사진만 조회·추가·수정·삭제할 수 있다.
- 추천·저장 코디·피드백은 자기 추천 세션에만 붙일 수 있다.

## 4. 예외 처리

| 상황 | 화면 안내 |
|---|---|
| 비밀번호 확인이 다름 | 비밀번호 확인이 달라요. |
| 틀린 이메일·비밀번호 | 이메일 또는 비밀번호가 맞지 않아요. |
| 이미 가입된 이메일 | 이미 가입된 이메일이에요. 로그인해 주세요. |
| 이메일 인증을 켠 설정 | 가입 신청이 됐어요. 받은 메일의 인증 링크를 누른 뒤 로그인해 주세요. |
| Supabase 주소 설정 오류 | Supabase 주소(SUPABASE_URL)가 잘못된 것 같아요. 관리자에게 알려 주세요. |
| 서비스 키를 앱에 넣음 | 앱 실행을 멈추고 공개 키로 바꾸라고 안내 |
| 프로필 없음 | 프로필을 생성하세요. |
| 옷장이 비어 있음 | 등록된 의류가 없습니다. |
| 의류명·사진 누락 | 의류명을 입력하세요. / 사진을 업로드하세요. |
| 조합할 옷이 부족 | 상의+하의+신발 또는 원피스+신발 조합이 필요합니다. |
| 조건에 맞는 코디 없음 | 추천할 수 있는 코디가 없습니다. |
| 구매 후보·저장 코디 없음 | 아직 구매 후보가 없어요… / 저장된 코디가 없습니다. |
| 가상 착용: 사람 없는 사진 | 사진에서 사람을 찾지 못했어요. 몸이 잘 보이게 다시 찍어 주세요. |
| 가상 착용: 안전 필터 | 결과가 안전 필터에 걸렸어요. 다른 사진으로 다시 해 보세요. |
| 가상 착용: 무료 GPU 사용량 초과 | 오늘 쓸 수 있는 무료 GPU 사용량을 다 썼어요. 첫 사용 24시간 뒤에 다시 채워져요… |
| 가상 착용: 허용 안 된·만료된 옷 사진 주소 | 허용하지 않은 주소… / 옷 사진을 가져오지 못했어요 (주소가 만료됐을 수 있어요)… |
