## 5. 미검증 항목

- 배포 주소에서 서버가 잠들었다 깨어난 직후의 첫 화면·첫 AI 분류 시간, 직접 추가 10장 한 번에 올리기 (무료 서버 메모리), 휴대폰 화면 (2026-11-07 배포 확인은 노트북 화면·사진 1장)
- 웹 체험판의 휴대폰 사진 192장 정확도 (f16 가중치 + 브라우저 크기 조정, 재지 않음)

- '샀어요'를 실제 Supabase에서 중간 실패시키는 시험 (가짜 Supabase로만 확인)
- ZeroGPU에서 실제 가상 착용 시간, 사용량 차감 방식 (특히 앱 안 창) (T-07, T-08)
- 실제 휴대폰 브라우저에서 카메라 촬영 (앱 안 창 / 새 창)
- 실제 사용자 시험 (T-09)
- 분류기의 실제 사용자 휴대폰 사진 성능 (시험용 192장은 공개 데이터 clothing-dataset 출처이고 라벨을 개발자가 붙임)
- 실제 휴대폰으로 올린 사진의 회전 처리 (앱·웹 체험판)
- 직접 추가 여러 장·정보 수정을 실제 Supabase와 배포 주소에서 (사진 10장 올리기 시간, 무료 서버 메모리), 실제 휴대폰 브라우저에서 카드 스크롤 높이 (주소창 높이에 따라 달라짐)
