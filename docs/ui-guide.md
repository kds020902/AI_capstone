# 화면 공통 기준 (PC 웹, Streamlit)

갱신: 2026-11-22 · 처음 적용한 화면: '오늘의 추천' (`screens/recommend.py`)
내 옷장·사기 전에 맞춰보기·저장 코디를 고칠 때 이 기준을 따른다. Streamlit 1.66(Python 3.10은 1.65)의 테마와 기본 컴포넌트만 쓰고, 화면에 CSS를 넣지 않는다.

## 1. 글자 크기와 읽는 순서

색을 구분하지 못해도 크기·굵기로 읽는 순서가 보여야 한다.

| 단계 | 쓰는 것 | 크기(기본 16px 기준) | 예 |
|---|---|---|---|
| 화면 제목 | `st.title` | 44px | 오늘의 추천 |
| 구역 제목 | `st.subheader` | 28px | 추천 조건, 추천 결과 |
| 카드 제목 | `st.markdown("##### …")` | 20px | 1위 · 82.9% |
| 본문·핵심 값 | `st.markdown`, 핵심 값은 `**굵게**` | 16px | 상의 · **블랙 기능성 티셔츠** |
| 보조 정보 | `st.caption` | 14px, 글자색 60% | 날씨 출처, 계산 근거, 참고 안내 |

- 한 화면에 `st.title`은 하나. 구역 제목은 화면을 크게 나눌 때만 쓴다.
- 목록의 핵심 값(옷 이름 등)은 굵게, 그 앞의 분류(상의·하의…)는 보통 굵기로 둔다.

## 2. 여백

Streamlit 기본 간격(요소 사이 16px)을 그대로 쓰고, 따로 간격을 넣지 않는다.

| 관계 | 값 | 만드는 방법 |
|---|---|---|
| 항목 안 (한 덩어리의 줄) | 8px 안팎 | 한 `st.markdown` 안에서 줄바꿈(`"  \n"`)이나 목록으로 묶기 |
| 관련 항목 사이 | 16px | 요소를 따로 두면 기본 간격 |
| 구역 사이 | 32px | `st.columns(..., gap="medium")` (2rem), 구역 제목의 위 여백 |

## 3. 배치

- 조건과 결과가 함께 있는 화면은 `st.columns([1, 2], gap="medium")`: 왼쪽에 조건과 실행 버튼, 오른쪽에 결과. 휴대폰 폭에서는 Streamlit이 위아래로 쌓으므로 안내 문구에 '왼쪽·오른쪽'을 쓰지 않는다.
- 제목 바로 아래에는 지금 적용 중인 조건을 한 줄로 쓴다. 조회 실패·기본값 사용 같은 상태는 그 줄 바로 밑에 붙인다.
- 자주 쓰는 입력은 바로 보이게, 가끔 쓰는 입력은 `st.expander`에 묶는다. 접힌 칸 안의 값을 처음 값에서 바꿨으면 expander 바로 아래 `st.caption("적용 중인 세부 설정: …")`으로 알린다. expander 제목은 바꾸지 않는다 (펼친 상태가 흐트러지지 않게).
- 결과 영역은 결과가 나오기 전에도 비워 두지 않고, 다음 행동을 한 문장으로 `st.info`에 쓴다.
- 1280px 폭에서 결과 영역은 약 530px이다. 긴 이름을 `+`로 이어 쓰지 말고 한 줄에 하나씩 쓴다.

## 4. 테두리와 안내 상자

- 테두리(`st.container(border=True)`)는 **반복되는 결과**(추천 카드, 저장 코디, 옷 카드)를 나누는 데만 쓴다. 조건·설명은 제목·정렬·여백으로 묶는다.
- 펼쳐 보기(`st.expander`)는 근거·피드백처럼 필요할 때만 보는 내용에 쓴다.
- 안내 상자의 뜻을 섞지 않는다.

| 상자 | 쓰는 때 | 예 |
|---|---|---|
| `st.info` | 다음 행동 안내, 결과에 딸린 참고 | 추천 전 안내, 저녁 대비 |
| `st.warning` | 결과를 해석할 때 알아야 할 제약 | 날씨 조회 실패, 겉옷 없음, 옷 부족 |
| `st.error` | 요청한 일이 안 됨 | 추천할 코디가 없음 |
| `st.success` / `toast` | 저장·기록 완료 | 코디 저장, 좋아요·별로 |

경고는 관련 결과 가까이에 둔다: 결과 전체에 해당하면 결과 목록 바로 위, 한 결과에만 해당하면 그 카드 안.

## 5. 버튼

- 화면(또는 구역)에서 가장 중요한 실행 하나만 `type="primary"`. 조건 영역에서는 `width="stretch"`로 폭을 채운다.
- 카드 안의 버튼은 보조 버튼으로 한 줄에 모은다: `st.container(horizontal=True, gap="small")`.
- 버튼 문구는 '무엇을 하는지'로 쓴다: 코디 추천받기, 이 코디 저장, 내 옷장에서 옷 넣기.
- 다른 메뉴로 보내는 버튼은 `screens/common.py`의 `go_to_page(문구, 메뉴 이름, key)`를 쓴다 (사이드바 메뉴 key `nav_page`를 바꿈).

## 6. 색과 명암

`.streamlit/config.toml`에 밝은·어두운 모드를 함께 정해서 사용자 시스템 설정을 따른다.

| 항목 | 값 | 명암비 (실제 브라우저에서 잰 값, 2026-11-22) |
|---|---|---|
| 강조색(기본 버튼·선택 표시) | `#2F5BD3` | 흰 글자와 5.90:1 (예전 빨간색 `#FF4B4B`는 3.30:1) |
| 본문 글자(밝은 모드) | `#16181F` | 흰 배경 17.7:1 |
| 보조 글씨 `st.caption` | 글자색 60% | 흰 배경 4.64:1 (예전 3.7:1) |
| 사이드바 글자 | `#0B0C10` | 사이드바 보조 글씨 4.97:1 |
| 안내 상자 글자 | Streamlit 기본 | `st.info` 6.67:1 |

- 일반 글자는 4.5:1 이상. 보조 글씨를 더 흐리게 하려면 색 대신 크기로 구분한다.
- 색만으로 뜻을 전하지 않는다: 경고 상자에는 문장으로 무엇이 문제인지 쓴다.
